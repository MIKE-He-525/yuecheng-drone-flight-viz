# 越城区无人机飞行服务 · 数据预处理与看板

越城区无人机飞行服务数据的清洗、可视化与交互看板项目。

## 功能

- **数据清洗**：`clean_data.py` 将原始 CSV 清洗并输出到 `clean_data/`
- **静态图表**：`visualize.py` 生成统计 PNG（需联网加载 OSM 底图）
- **交互看板**：`dashboard/` 含 HTML 模板与构建脚本；`dashboard.html` 为单文件交付物

## 环境

Python 3.10+ 推荐。

```bash
pip install -r requirements.txt
```

## 快速开始

```bash
# 1. 清洗数据（需本地放置原始 CSV，见 数据说明.md）
python clean_data.py

# 2. 生成静态图（可选）
python visualize.py

# 3. 构建看板 JSON 与单文件 HTML
python dashboard/build_dashboard.py
```

|------|----------|

| `dashboard/dashboard.html` | 同上 |

克隆后请先准备原始数据并依次运行清洗与构建脚本。

- 原始数据目录 `越城无人机数据+字段描述/` 需自行准备，不上传 GitHub。
- 看板含机场坐标、飞行轨迹、设备 SN 等**敏感地理与飞行信息**，**仅建议本地或内网打开**，勿部署到公开静态托管。
- 字段与清洗规则见 [`数据说明.md`](数据说明.md)。
- 若仓库曾推送过含数据的旧版本，Git 历史中可能仍保留；新 clone 的默认分支不会包含上述忽略文件。建议保持 **Private** 可见性。

## 看板使用指南

本文说明如何打开、浏览和使用 **`dashboard/dashboard.html`** 单文件看板（总览 + 空间地图）。

### 打开方式

**推荐：直接打开单文件**

1. 找到 `dashboard/dashboard.html`
2. 用 Chrome / Edge 等现代浏览器**双击打开**，或拖入浏览器窗口

看板为**单 HTML 文件**，业务数据已内嵌，无需安装后端或数据库。

**网络要求**（首次打开需联网）：

| 资源 | 用途 |
|------|------|
| Google Fonts | 界面字体 |
| Chart.js | 总览页图表 |
| Leaflet | 地图交互 |
| CARTO 地图瓦片 | 底图显示 |

若图表或地图空白，请检查网络、广告拦截插件，或刷新页面。

**开发调试（可选）**

维护人员修改 `index.html` / `map.html` 模板后，需先运行 `python dashboard/build_dashboard.py` 生成 `data.json`、`map_data.json`，并用本地 HTTP 服务访问（不能直接 `file://` 读 JSON）：

```bash
cd dashboard
python -m http.server 8080
# 访问 http://localhost:8080/index.html 或 dashboard.html
```

### 总览看板

**顶部信息**：标题 + 数据时间范围（来自清洗后飞行记录）。

**KPI 卡片**

| 指标 | 含义 |
|------|------|
| 飞行记录 | `fly_record` 表记录条数 |
| 机场点位 | 清洗后机场数量 |
| 有效遥测点 | 经纬度有效且非 `(0,0)` 的 GPS 点数 |
| 预定义航线 | `route` 表航线数量 |

**统计图表**

| 图表 | 说明 |
|------|------|
| 飞行次数 — 按月趋势 | 按实际起飞时间汇总的月度飞行量 |
| 飞行类型分布 | 任务飞行 / 自由飞行等 |
| 飞行记录 — 厂商分布 | 大疆、一电、纵横等 |

| 飞行时长分布 | 时长 ≤ 60 分钟的直方图 |
| 任务飞行 Top 8 | 按执行次数排序的常见任务 |

鼠标悬停图表可查看具体数值。右上角提供 5 套主题（Claude / Material / Vercel / Linear / SaaS），选择会保存在浏览器本地。

### 空间地图

#### 左栏 · 概览与图层

**空间数据概览（迷你 KPI）**

| 指标 | 含义 |
|------|------|
| 机场 | 地图上的机场点数 |
| 轨迹 | 可绘制的飞行轨迹条数（至少 2 个有效 GPS 点） |
| 遥测点 | 参与地图的有效 GPS 点总数 |
| 行政内 | 有效 GPS 点落在越城区行政区划内的比例 |
| 飞行记录 | 飞行记录总条数 |
| 预定义航线 | 航线数量 |

**图层控制**

| 开关 | 效果 |
|------|------|
| 机场点位 | 显示/隐藏各厂商机场圆点 |
| 机场覆盖半径 | 显示/隐藏以机场为圆心的覆盖圈 |
| 飞行轨迹 | 显示/隐藏轨迹线 |
| 显示越城区行政区划 | 显示/隐藏区划边界 |
| 仅显示行政区内轨迹 | 只保留「轨迹内 ≥50% 遥测点落在区内」的飞行 |
| 重置默认视野 | 地图缩放回默认范围（以机场集群为中心） |

**图例（地图左下角）**

- 红 / 蓝 / 绿：大疆 / 一电 / 纵横
- 橙色线：越城区边界
- 灰色线：无飞行记录关联的轨迹（仅有遥测、无 `fly_record` 匹配）

#### 右栏 · 轨迹筛选

筛选标题旁的 **`563 / 563`** 表示：**当前条件下匹配的轨迹数 / 轨迹总数**。

- **厂商 / 任务类型**：点击标签切换；「全部」表示不限
- **数值滑块（双拖柄）**：区间筛选，拖动左右手柄设定范围

| 筛选项 | 数据来源 | 说明 |
|--------|----------|------|
| 飞行时长（分钟） | 飞行记录 `real_duration` | 无记录关联的轨迹不参与该维度限制 |
| 飞行距离（km） | 飞行记录 `real_distance` | 同上 |
| 飞行轨迹最大高度（m） | 遥测点 `height` 的最大值 | 该轨迹所有航点中的最高海拔 |
| 飞行最大速度（km/h） | 由相邻遥测点推算 | 已过滤 GPS 跳点造成的异常高速 |

若某条轨迹在某个维度上**没有数据**，该维度**不会因此排除**该轨迹。点击 **「重置筛选」** 恢复默认。

筛选区下方显示当前条件摘要（chips）及结果数量。

#### 右栏 · 轨迹列表

| 功能 | 操作 |
|------|------|
| 定位并高亮 | 点击列表中某一条 |
| 仅看此条 | 选中后点击，地图只显示该轨迹 |
| 取消选中 | 清除高亮与「仅看此条」状态 |
| 搜索 | 按轨迹 ID 或任务名过滤列表 |
| 排序 | 按遥测点数 / 时长 / 距离排序 |

点击轨迹后：选中轨迹**加粗高亮**，其余**半透明**；地图自动缩放并弹出详情框。

**地图操作**：滚轮缩放、拖拽平移（Leaflet 默认）；窄屏下三栏布局会自动上下堆叠。

### 常见疑问

**Q：预定义航线 786 条，为什么地图轨迹只有 563 条？**

二者统计的不是同一类数据：

| 指标 | 含义 |
|------|------|
| 预定义航线（786） | `route` 表中的**航线模板/配置**，无航点 GPS，不能画在地图上 |
| 地图轨迹（563） | `fly_telemetry` 中按 `fly_record_id` 分组、**≥2 个有效 GPS 点**可画线的实际飞行 |

786 条是系统里配置的航线总数；563 条是遥测里实际能画出 GPS 轨迹的飞行次数。并非每条航线都被执行过，也不是每次飞行都有完整遥测。

**Q：筛选显示 `400 / 563` 而不是 `563 / 563`？**

可能勾选了 **「仅显示行政区内轨迹」**。取消勾选即可。

**Q：轨迹数 563 和飞行记录数（约 3,298）不一致？**

- **563** = 遥测中能连成线的 `fly_record_id` 数量
- 其中约 **213 条**没有对应的飞行记录（地图上为灰色轨迹）
- 飞行记录 KPI 统计的是 `fly_record` 全表，口径不同

**Q：「有效遥测点」和 CSV 总行数为何不同？**

清洗后 CSV 可能保留 `(0,0)` 等无效 GPS；看板只统计**有效 GPS**。

**Q：地图加载很慢？**

单文件内嵌地图数据约 1.2MB，**首次进入地图页**解析 JSON 可能需要数秒，属正常现象。

**Q：数据更新后看板如何刷新？**

```bash
python clean_data.py
python dashboard/build_dashboard.py
```

新生成的 `dashboard/dashboard.html` 即为最新交付物。
