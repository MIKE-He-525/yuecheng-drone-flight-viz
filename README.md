# 越城区无人机飞行服务 · 数据预处理与看板

越城区无人机飞行服务数据的清洗、可视化与交互看板项目。


## 功能

- **数据清洗**：`clean_data.py` → `clean_data/`（CSV + 清洗日志）
- **Excel 交付**：`export_data_workbook.py` → `clean_data/数据说明与清洗交付.xlsx`
- **静态图表**：`visualize.py` → `figures/`（需联网加载 OSM 底图）
- **交互看板**：`dashboard/` 模板 + `build_dashboard.py` → 单文件 `dashboard.html`

## 环境

Python 3.10+ 推荐。

```bash
pip install -r requirements.txt
```

## 快速开始

```bash
# 1. 清洗（原始数据在 越城无人机数据+字段描述/）
python clean_data.py

# 2. 可选：Excel 交付物 / 静态图
python export_data_workbook.py
python visualize.py

# 3. 构建看板 JSON 与单文件 HTML
python dashboard/build_dashboard.py
# 双击打开 dashboard/dashboard.html（需联网加载 CDN）
```

字段、清洗规则与分析口径见 [`数据说明.md`](数据说明.md)（含进度记录）；本 README 为项目入口与看板使用说明。

## 看板使用指南

如何打开、浏览 **`dashboard/dashboard.html`**（总览 + 空间地图同页）。

### 打开方式

**推荐：直接打开单文件**

1. 找到 `dashboard/dashboard.html`
2. 用 Chrome / Edge 等现代浏览器双击打开，或拖入浏览器窗口

单 HTML 内嵌业务数据，无需后端。首次打开需联网：

| 资源 | 用途 |
|------|------|
| Google Fonts | 界面字体 |
| Chart.js | 总览图表 |
| Leaflet | 地图交互（2D） |
| MapLibre GL | 图层「3D 视图」开启后的倾斜三维场景 |
| AWS Terrarium DEM | 3D 地形高程瓦片 |
| OpenFreeMap | 3D 立体建筑矢量瓦片（无需 API Key） |
| CARTO 瓦片 | 底图（浅色；Linear 主题为暗色） |

图表或地图空白时，检查网络、广告拦截，或强制刷新。

**开发调试（可选）**

修改 `index.html` / `map.html` / `map_section.css` 后：

```bash
python dashboard/build_dashboard.py
cd dashboard
python -m http.server 8080
# http://localhost:8080/dashboard.html
# 或分别调试 index.html / map.html（需 HTTP，不能 file:// 读 JSON）
```

### 总览看板

**顶部**：标题 + 数据时间范围（来自清洗后飞行记录）。

**KPI**

| 指标 | 含义 |
|------|------|
| 飞行记录 | `fly_record` 条数 |
| 机场点位 | 清洗后机场数 |
| 有效遥测点 | 经纬度有效且非 `(0,0)` 的 GPS 点数 |
| 预定义航线 | `route` 航线数 |

**图表**：月度飞行趋势、飞行类型、厂商分布（记录 / 机场）、时长分布（≤60 分钟）、任务飞行 **Top 12**（`build_dashboard.py` 对任务飞行 `task_name` 统计取前 12）。

**数据解读与法律备注**（与 Top 12 并排半宽卡片，内容可滚动）：

| 区块 | 要点 |
|------|------|
| 数据解读 | 规模（3298 / 36 / 786 / 563 / 213 灰轨）、时间口径、统计口径、用途边界 |
| 法律备注 | 《民用航空法》（2026-07-01 施行）第 34 / 61 / 73–77·82 / 157–161 / 225 / 258 条摘要 |
| 免责 | 仅供监测分析，不构成许可或合规结论 |

主题（Claude / Material / Vercel / Linear / SaaS）同步更新图表配色与地图底图。

### 空间地图

#### 图层（地图上方横条）

| 开关 | 效果 |
|------|------|
| 机场点位 / 覆盖半径 | **默认关**；勾选后显示 |
| 飞行轨迹 | 默认开 |
| 显示越城区行政区划 | 区界（叠在轨迹之下） |
| 仅显示行政区内轨迹 | 轨迹内 ≥50% 点在区内 |
| 立体建筑 | 默认开；仅 3D 生效（缩放约 ≥13；长轨请滚轮放大） |
| 3D 视图 | **默认关**；手动开启后进入 MapLibre；选轨不自动开关 |
| 地形 | **默认开**；仅 3D 时生效；与 3D 开关独立，换轨不重置 |
| 重置默认视野 | 回到默认范围；**3D 模式下**同时恢复该轨默认相机（俯仰约 60°、方位约 -20°） |

**图例**：红/蓝/绿 = 大疆/一电/纵横；橙线 = 区界；灰线 = 无 `fly_record` 的孤儿轨迹。

**数据说明**（地图标题下）：橙线为行政区划（统计用），≠ 法定空域/管制空域；「行政区内轨迹」按点占比 ≥50% 筛选，不代表可飞或已获许可。

#### 左栏 · 筛选与列表

筛选旁 **`n / 563`** = 当前匹配数 / 可绘制轨迹总数。

| 筛选项 | 说明 |
|--------|------|
| 厂商 / 任务类型 | 芯片；「全部」不限 |
| 起飞时间 | 2024-09-14～2026-05-21；可画轨迹实质约到 2025-04。无起飞时间**不因此排除**；收窄日期时状态条提示「含 N 条无起飞时间」 |
| 时长 / 距离 / 高度 / 速度 | 双拖柄，默认覆盖真实极值；某维无数据**不排除**该轨 |

| 操作 | 行为 |
|------|------|
| 点列表或轨迹 | 定位、**右上角详情卡**；选中轨高亮，**其余置灰**（不自动「仅看此条」）；**不**自动进 3D；无 Leaflet 轨迹弹窗 |
| 加入对比 | ① 选中一条 → ② 点「加入对比」进入待选 → ③ 再点另一条（列表或地图）进入对比。待选中可点「取消选择」或再点已选轨取消。上限 **2** 条 |
| 对比中展示 | 地图双轨同级高亮、时序**单指标**双曲线叠加、摘要表两行并列、3D 双管（若已开）；**无主副之分**（色相区分轨 ID） |
| 换对比轨 | 对比中点「换对比轨」→ 再点第三条替换对比对象之一 |
| 退出对比 | 退出对比展示，保留当前选中单轨 UI |
| 取消选中 | 恢复全部轨迹颜色、卸下时序抽屉、**退出对比并取消待选**；不强制退出 3D/地形 |
| 时序抽屉 | 顶部**箭头**开合：展开占位并缩小地图；收起**仅留箭头条**；再点展开 |
| 仅看此条 | 列表旁按钮手动开启，只显示选中轨（对比模式下不可用） |
| 时序曲线 | 单轨：高度 / 速度 / 累计距离同图；**对比**：高度/速度/距离三按钮切换，一次叠加两条；**播放在左侧图例栏顶部** |
| 位置标点 | 悬停/播放时 2D/3D 联动；**对比时两条轨均显示圆点 + 点位信息**（高度/速度/距离/经纬度，标题为 `#id`） |
| 搜索 / 排序 | ID / 任务名 / 机场 / 机库 SN / 任务 ID / 无人机 SN；按点数 / 时长 / 距离 |
| 改筛选 | 选中轨若不在结果中 → 自动取消选中、卸下时序；对比集同步剔除，不足 2 条则退出对比（**保留** 3D/地形开关）；滑块约 120ms 防抖 |

**3D 选中视图**

- 需在图层栏勾选 **「3D 视图」** 才进入 MapLibre；选轨 / 换轨 / 清选**不会**自动开关 3D 或地形
- 「地形」为独立全局开关（默认开）
- 航迹：自定义 **WebGL 细管**（弦上线性加密）；垂直口径 **DEM + AGL**（优先 `elevation`）；**对比模式**同时绘制 2 条细管
- 立体建筑：OpenFreeMap（可关）；其余贴地轨在有选中时置灰
- 右上角详情卡与 2D 共用（对比时为两行摘要表，形式对等）
- 鼠标：左键平移、右键方位与俯仰
- 对比播放：两条轨的 WebGL 位置珠与 HTML 点位气泡同步更新（Leaflet 在 3D 下不可见，故标点挂在 MapLibre 层）

**地图操作**：滚轮缩放、拖拽平移；窄屏上下堆叠。

### 常见疑问

**Q：预定义航线 786，地图轨迹只有 563？**

| 指标 | 含义 |
|------|------|
| 预定义航线（786） | `route` 模板，无航点 GPS |
| 地图轨迹（563） | 遥测按飞行 id 分组且 ≥2 有效 GPS 点可画线 |

**Q：筛选显示 `400 / 563`？**

可能勾了「仅行政区内轨迹」或其它条件过严；重置筛选或取消勾选即可。

**Q：收窄起飞时间后仍有灰色轨迹？**

约 213 条孤儿轨无 `start_time`，按「空值不排除」仍会留下；状态条会提示条数。

**Q：563 和飞行记录（约 3,298）不一致？**

口径不同：563 是可画线遥测飞行；其中约 213 条无对应飞行记录（灰线）。

**Q：时间滑块后半段几乎没轨迹？**

记录可到 2026-05，GPS 遥测实质约到 2025-04。详见 `数据说明.md` §8.4。

**Q：怎么对比两条轨迹？**

选中一条 →「加入对比」→ 再点另一条。对比中两条轨并列展示（地图/曲线/摘要/3D/点位信息均对等）。点「退出对比」或「取消选中」结束。

**Q：3D 里建筑高度和飞行高度怎么比？**

两者在 3D 场景里都按「相对地面 + DEM」放置，可目视对比。时序图上的「高度」仍是遥测**海拔** `height`，数值不要与建筑 AGL 或相对起飞 `elevation` 直接等同。详见 `数据说明.md` §8.3。

**Q：为什么 3D 里看不到立体建筑？**

需勾选「立体建筑」，并滚轮放大到约 13 级以上；长航迹默认俯视较远。另需能访问 `tiles.openfreemap.org`。

**Q：地图加载慢？**

内嵌地图数据约 3.4MB（含时序与相对高度）；滚到地图区才解析，属正常。

**Q：数据更新后如何刷新看板？**

```bash
python clean_data.py
python export_data_workbook.py   # 可选
python dashboard/build_dashboard.py
```

生成的 `dashboard/dashboard.html` 即为最新交付物。
